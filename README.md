# ProxmoxManagerDashboard 🚀

Custom dashboard for monitoring infrastructure resources such as CPU, RAM, storage, and virtual machines. Includes functionality for bulk virtual machine creation with custom or default configurations.

## ✨ Features
* **Real-Time Monitoring:** Visualize CPU, RAM, and storage usage across Proxmox nodes.
* **VM Management:** Detailed list and health status of all virtual instances.
* **Bulk Creation:** Automate the creation of multiple VMs with custom or template-based settings.
* **Modern Interface:** Intuitive UI designed for critical metrics at a glance.

## 🚀 Quick Start
1. **Clone the repository:**
   `git clone https://github.com/MrJakeee/ProxmoxManagerDashboard.git`
2. **Install dependencies:**
   `npm install` (or your specific package manager command)
3. **Set up Environment:**
   Create a `.env` file with your Proxmox API URL and Token credentials.
4. **Run the app:**
   `npm start`

## 🛠️ Tech Stack
* **Core:** Node.js / Proxmox VE API
* **Frontend:** HTML5, CSS3, JavaScript
